# Geoለም AI

Geoለም AI (pronounced Geo-lem AI) joins three parts: Geo for geospatial (satellite and map data), ለም (lem), the Amharic word for "fertile", as in ለም መሬት, "fertile land", and AI for artificial intelligence. Together the name means geospatial intelligence for fertile, productive land.

Showcase of the Geoለም AI home page: geospatial tools for farmers, NGOs and government in Ethiopia.

Try the live app: geolemai.onrender.com (the first visit can take up to a minute while the free server wakes up).

This repository holds only the built website files of the home page. The source code is private.
